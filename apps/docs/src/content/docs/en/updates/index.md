The `docs/updates/` folder in the monorepo holds technical decision records that
affect the port to the Go backend. Two main documents:

- [`elearning-rls`](/en/updates/elearning-rls) — translating the old Supabase
  RLS policy into rules in the Go e-learning services.
- [`findings`](/en/updates/temuan) — a list of bugs and oddities in the old code
  that were deliberately **not** fixed to keep behaviour parity with production.

Other update documents will be added as the porting progresses.
